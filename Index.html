            <h2>Understanding the Hypertext Transfer Protocol (HTTP)</h2>

            <p>Welcome to my IT 3203 web development project research site. This website serves as an exploratory portfolio tracking the architecture, progression, and underlying mechanisms of the Hypertext Transfer Protocol—the fundamental foundation of data communication across the World Wide Web.</p>

            

            <div class="highlight-box">

                <h3>Abstract</h3>

                <p>From simple text document retrieval in early web eras to multiplexed streams and UDP-based transport layers in modern cloud ecosystems, HTTP has continuously adapted to meet escalating demands for performance, security, and lower latency.</p>

            </div>

        </section>


        <!-- Key Terms Overview Section -->

        <section>

            <h3>Key Terms Snapshot</h3>

            <ul>

                <li><strong>Client-Server Architecture:</strong> The foundational paradigm where requests are initiated by a user agent and answered by an origin server.</li>

                <li><strong>Statelessness:</strong> Each request-response cycle is independent and untracked by default.</li>

                <li><strong>Multiplexing:</strong> The ability to interleave multiple requests and responses concurrently over a single connection.</li>

            </ul>
